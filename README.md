# App support site

Static GitHub Pages site for Francesco G. Add future apps as APP/support/index.html and APP/privacy/index.html, with an entry in index.html. No build tool or JavaScript is required.

Proposed repository: IronTony/irontony.github.io. Proposed support URL: https://irontony.github.io/shiftix/support/ . Proposed privacy URL: https://irontony.github.io/shiftix/privacy/ . These URLs are not live until published.
